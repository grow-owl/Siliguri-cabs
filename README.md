# HillWay Cabs (Siliguri Cabs) 🚖
> **Your Journey, Our Responsibility.**

Premium single-page outstation & airport taxi booking website for Siliguri, Darjeeling, Gangtok, Kalimpong, Bhutan & Dooars.

## Features
- **Modern Luxury UI:** Custom Charcoal, Muted Gold, Warm Cream, and Crisp White aesthetics.
- **Cross-Platform Responsive:** 100% optimized for iOS (iPhone Safari), Android, Tablet, Laptop, and Desktop.
- **Interactive Booking Engine:** Instant ride quote generator with pre-filled WhatsApp click-to-chat integration.
- **Dual Route Collections:**
  - Siliguri to Outstation Cabs (Gangtok, Darjeeling, Kalimpong, Mirik, Kurseong, Bhutan, Lataguri, Lava).
  - Bagdogra Airport (IXB) Transfers with flight delay buffer guarantee.
- **Fleet Showcase:** Executive Sedan, Comfort MPV, Innova Crysta, and Tempo Traveller.
- **Trust Elements:** Mountain-expert chauffeur certifications, transparent fixed pricing, verified customer reviews, and FAQ accordion.
- **Floating Contact Bar:** 1-tap Call Desk and WhatsApp buttons on mobile viewports.

## Tech Stack
- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS v3
- **Icons:** Lucide React + Custom Vector SVGs
- **Typography:** Playfair Display + Inter

## Development & Build

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
